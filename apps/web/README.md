# apps/web

Next.js 16 (App Router) frontend. Premium SaaS UI: landing page, dashboard, resume
intelligence, skill gaps, job matching, roadmap, AI interview, analytics. See
[docs/UI_ARCHITECTURE.md](../../docs/UI_ARCHITECTURE.md) for route map and rendering strategy.

## Development

Run from the repo root (npm workspaces):

```bash
npm run dev:web
```

Or from this directory: `npm run dev`. Opens on [http://localhost:3000](http://localhost:3000).

## Stack notes

- **Next.js 16** — Turbopack is the default bundler for both `dev` and `build` (no flag
  needed). `next lint` was removed upstream; linting runs via the ESLint CLI directly
  (`npm run lint`), using flat config (`eslint.config.mjs`).
- `AGENTS.md` / `CLAUDE.md` at the root of this app are regenerated by `next dev` and point AI
  coding agents at the Next.js docs bundled in `node_modules/next/dist/docs/` — useful since
  Next.js 16 has real breaking changes vs. older training data (async `params`/`searchParams`,
  `middleware.ts` → `proxy.ts`, etc.). Keep them committed; don't hand-edit the managed block.
